# Spelautomat — demo

Built demo of a D3 pictogram slot machine: https://tiramisioux.github.io/slot-machine/

Options in the URL: `?scheme=orange-green|orange-teal`, `&flip=1`, `&info=1` (notes appear when the wheels stop), `&plain=1` (hover a landed chemical: its wheels turn over to an easy-read story).
This repo only holds the build. It is regenerated from the private source on every push to its `main`.
